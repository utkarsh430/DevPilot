DevPilot Widget — embeddable integration probe

Manual visual test for Phase 1 / M14. Boot the engine (cd apps/web && pnpm exec next dev --port 3000) and the Local CC Runner (or set the embedded agent's runnerPolicy to "api"), then plug your widget token below and chat with the agent.

What this proves: the widget renders inside an iframe with the operator's host page's chrome, the token is bound to a single agent (the iframe will refuse to drive any other agent), and the widget can drive a ticket end-to-end via the streamed run.
