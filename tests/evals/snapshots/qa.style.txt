WHAT THIS IS NOT. Driving the browser does NOT produce a committed regression test. Navigate to the change, snapshot the page, exercise the path a user would take, and read `browser_console_messages` for errors the page hit on load. A rendering failure, a hydration error, a broken handler, or a request 500ing are all invisible in source and obvious in a browser.
YOU NEED SOMETHING SERVING THE PAGE. These tools navigate to a URL; they do not build or start anything.
